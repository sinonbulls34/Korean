Learning Path

初學路線

先把字母、嘴型與方塊字結構建立穩，再把聲音放進旅行與生活句子。注音只作輔助，發音仍以韓語口腔位置為主。

Hangul 40

韓文 40 音

母音看嘴型，子音聽送氣、緊音與收尾位置。每張卡片都能播放韓語示範音。

基本母音 先分清楚張口、圓唇、扁平嘴型。

Pronunciation Rules

發音規則

先用最常遇到的規則建立耳朵：收音、連音、送氣與緊音。每個例子都能慢速重聽。

Reading Rule

韓字是一個方塊，不是一條線。

每個音節通常由「初聲子音 + 中聲母音」組成，底部可再加「終聲收音」。例如 가 是 ㄱ + ㅏ， 감 是 ㄱ + ㅏ + ㅁ。讀字時先找母音方向，再回頭補上子音與收音。

ㄱ ㅏ ㅁ
감 kam/gam
