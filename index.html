Learning Path

初學路線

先能準確讀字，再把字放進句子。這條路線以台灣學習者熟悉的注音提示輔助，但核心仍以韓語發音為準。

Hangul 40

韓文 40 音

母音看嘴型，子音聽送氣、緊音與收尾位置。每張卡片都能播放韓語示範音。

基本母音 先分清楚張口、圓唇、扁平嘴型。

Reading Rule

韓字是一個方塊，不是一條線。

每個音節通常由「初聲子音 + 中聲母音」組成，底部可再加「終聲收音」。例如 가 是 ㄱ + ㅏ， 감 是 ㄱ + ㅏ + ㅁ。讀字時先找母音方向，再回頭補上子音與收音。

ㄱ ㅏ
가 ka/ga
ㄱ ㅏ ㅁ
감 kam/gam

Grammar Core

第一批文法核心

SOV

韓語把動詞放最後

中文常說「我吃飯」，韓語更接近「我飯吃」：저는 밥을 먹어요。

은/는

主題助詞

把話題端出來。저는 表示「至於我」，常用在自我介紹與對比。

이/가

主格助詞

標出句子的主語。前字有收音用 이，沒有收音用 가。

을/를

受格助詞

標出被動作影響的對象。밥을 먹어요、커피를 마셔요。
